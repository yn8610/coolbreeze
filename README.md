# CoolBreeze ❄️

Smart cooling dashboard for building owners and AI data centre operators in India.

See real-time cooling energy, live weather for your building's city, and estimated
savings — then apply smart-cooling suggestions with one tap.

- No installs, no credit card, free to use
- Works in any browser on any device
- Made by a school student as a startup project — see `docs/` for the full guides

## How to open

Go to https://yn8610.github.io/coolbreeze/ , click **Create account**, and try the
demo building with sample data.
