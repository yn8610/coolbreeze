# Glossary — Plain-English Dictionary

Every term we use, in one short line each. Added to whenever we meet a new word.

| Term | What it means (one line) |
|---|---|
| **App / Website** | A program people use in a web browser, like Google Docs. Ours is a website. |
| **Dashboard** | The main screen where you see your numbers and buttons. |
| **Scoreboard** | The top row of cards on our dashboard: energy now, savings today, status. |
| **kWh** | A unit of electricity (kilowatt-hour) — the thing your electricity bill counts. |
| **kW** | A unit of power — how much energy the cooling is pulling right now. |
| **Estimate** | A smart guess, not a measured number. We label ours clearly. |
| **Cooling share** | The part of the electricity bill that cooling uses (we use ~30% in the formula). |
| **Savings** | Money you don't spend because the building uses less electricity. |
| **Demo building** | A fake building filled with sample data so you can try everything instantly. |
| **Apply button** | The big green button that puts our suggestion into action in the demo. |
| **Alert** | A short message that tells you something important. |
| **localStorage** | A free storage space inside your browser where we keep accounts and data for now. |
| **HTML** | The language that builds the structure of a webpage. |
| **CSS** | The language that decides how a webpage looks. |
| **JavaScript** | The language that makes a webpage interactive (buttons, graphs, logic). |
| **Server / Backend** | A computer on the internet that stores data for many users. We don't have one yet. |
| **Hosting** | Putting your website on the internet so anyone can open it. |
| **GitHub / GitHub Pages** | A free place to store your project and get a free website link. |
| **Carbon emissions** | CO₂ released when electricity is made — less electricity means less CO₂. |
| **AI data centre** | A building full of computers that run AI — they get very hot and need heavy cooling. |
| **Weather API** | A free service on the internet that gives us weather for any city. Ours is Open-Meteo. |
| **Forecast** | The weather predicted for the next days. We show 5 days. |
| **Geocoding** | Turning a city name (e.g. "Chennai") into map coordinates so we can fetch its weather. |
| **API** | A way for a website to ask another service (like weather) for data automatically. |
